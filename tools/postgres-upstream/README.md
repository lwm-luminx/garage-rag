# Upstream series for pgsql-hackers

The three `v1-*.patch` files are `git format-patch` output of the `--enable-appstore`
series against PostgreSQL master 6a93535 (2026-09-29); `email-body.txt` is the plain-text
body of the reply on Wolfgang Walther's thread "PostgreSQL fails to start inside Nix' darwin
sandbox" (https://postgr.es/m/a90b5411-705f-4286-bd81-a26c520a6cfb%40technowledgy.de).
This folder exists so a Mac can pick the files up for sending; it is not part of the build.
