# Project history

Digests of every thread of the Claude project that built Garage 1.5 (2026-09-24 to 2026-10-07), written on
2026-10-07 when the project's state was moved into the repositories. Each thread has its outcome (PRs, files),
Rick's decisions with dates, the procedures and gotchas it found, what was still open, and where the knowledge
belongs. `project-chat-rules.md` is the project chat's own timeline of Rick's rules and the asks still open.

They are summaries written by Claude from the threads, so check a PR or the code before relying on a detail.
Thread ids (`cmsg_…`) identify the threads in the Claude project. Enterprise threads are in
`lwm-luminx/garage-enterprise`, `docs/project-history.md`. Secrets and personal data are `[redacted]`.
