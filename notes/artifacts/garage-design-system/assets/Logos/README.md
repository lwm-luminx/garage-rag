# Logos

- `garage-icon-1024.png`: the app icon (1024px, transparent corners). A lavender plus-and-leaf glyph on a violet tile. Use it for heroes and large placements.
- `garage-icon-256.png`: the same icon at 256px, for headers, the Wordmark lockup and favicons at 32–64px.
- `garage-enterprise-icon.svg`: the Garage | Enterprise icon, vector. The same glyph on a plum (`violet-500`, Enterprise) tile, with quarter-disc leaves and an inset hairline fence. Use it only with the Enterprise themes.
- `garage-enterprise-icon-512.png`: the Enterprise icon at 512px, for link previews and places that cannot take SVG.
- `garage-social-card.png`: the 1200×630 Open Graph card for garagerag.app.

Full colour only: never recolour, outline or re-draw either icon, and never use one edition's icon with the other edition's themes.
