# SearchField

A full-width search input (max 480px) with a leading magnifier in `ink-faint`, a `line-strong` border for 3:1, and a `violet-500` border plus a `violet-100` halo on focus.

- Accepts every `<input>` prop. Supply `label` for screen readers (it is visually hidden); the placeholder defaults to "Search your corpus".
- Use it for the corpus search (Search page, docs filter). Put results below it, not in a popover.
