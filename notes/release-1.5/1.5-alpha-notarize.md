# Garage 1.5 alpha: notarized Developer ID build

This runbook is for the Mac that holds these three things:
- `Developer ID Application: Richard Penwell (DWVXMLB45Y)`;
- `Developer ID Installer: Richard Penwell (DWVXMLB45Y)`;
- the notarytool keychain profile `Primary`.

Run it only after both test passes (M4 and M3) have come back clean. It builds, notarizes and checks. It does not tag, publish a release or touch `docs/appcast.xml`; those wait for Rick.

The steps follow `RELEASING.md` section 2, with the alpha differences called out.

## 0. Checkout

```bash
git fetch origin v1.5-alpha
git checkout --detach origin/v1.5-alpha
git rev-parse --is-shallow-repository   # must print false: CFBundleVersion is the commit count of HEAD
git rev-list --count HEAD               # this is the build number the app will carry
git status --short                      # must be empty
garage quit                             # no running Garage while building
```

If the clone is shallow, run `git fetch --unshallow` first.

## 1. Build, sign and notarize

```bash
aspect build //macapp/package:GarageApp        # thinned to arm64, signed Developer ID -> bazel-bin/macapp/package/GarageApp.zip
aspect run //macapp/package:notarize_all       # notarizes the app, builds + signs the .pkg, notarizes the .pkg (waits)
```

If notarization is rejected, save the log before retrying:

```bash
xcrun notarytool log <submission-id> --keychain-profile Primary
```

## 2. Staple the app, then build, notarize and staple the installer

`notarize_all` notarizes the app zip, but the `.pkg` it notarizes was built at build time, from the app before notarization. The app inside that package is therefore never stapled. Throw that package away and redo the installer from the stapled app. The order is: app notarized (done by `notarize_all`), then the app stapled, then the pkg built from it, then the pkg notarized and stapled.

```bash
rm -rf work dist && mkdir -p work/root dist
ditto -x -k bazel-bin/macapp/package/GarageApp.zip work/root/
VERSION=$(/usr/libexec/PlistBuddy -c 'Print CFBundleShortVersionString' work/root/Garage.app/Contents/Info.plist)

# The app: staple, and zip the stapled copy for Sparkle and the GitHub release
xcrun stapler staple work/root/Garage.app
xcrun stapler validate work/root/Garage.app
ditto -c -k --keepParent work/root/Garage.app dist/Garage-1.5-alpha.zip

# The installer, from the stapled app. Not relocatable, so it always installs to /Applications
# instead of "updating" a copy of Garage it finds somewhere else on the disk.
pkgbuild --analyze --root work/root work/component.plist
plutil -replace 0.BundleIsRelocatable -bool NO work/component.plist
pkgbuild --root work/root --component-plist work/component.plist \
  --install-location /Applications --identifier me.rickmark.garage-rag.pkg --version "$VERSION" \
  --sign "Developer ID Installer: Richard Penwell (DWVXMLB45Y)" --timestamp \
  dist/GarageInstaller_arm64.pkg

xcrun notarytool submit dist/GarageInstaller_arm64.pkg --keychain-profile Primary --wait
xcrun stapler staple dist/GarageInstaller_arm64.pkg
xcrun stapler validate dist/GarageInstaller_arm64.pkg
```

Record both notarization submission IDs: the app's from `notarize_all` and the installer's from this step.

In step 3, also run `xcrun stapler validate` on the app extracted from the zip. It should say the ticket is stapled.

## 3. Checks (RELEASING.md step 4)

```bash
rm -rf /tmp/garage-alpha && mkdir /tmp/garage-alpha && ditto -x -k dist/Garage-1.5-alpha.zip /tmp/garage-alpha
APP=/tmp/garage-alpha/Garage.app

# Apple Silicon only
lipo -archs "$APP/Contents/MacOS/"*
find "$APP" -name '*.so' -o -name '*.dylib' | xargs -I{} lipo -archs {} | sort | uniq -c   # arm64 only

# Stapled
xcrun stapler validate "$APP"

# Signatures and Gatekeeper
codesign --verify --deep --strict --verbose=2 "$APP"
spctl -a -vv "$APP"                                        # accepted, source=Notarized Developer ID
spctl -a -vv -t install dist/GarageInstaller_arm64.pkg     # accepted, source=Notarized Developer ID
pkgutil --check-signature dist/GarageInstaller_arm64.pkg

# No debug entitlement anywhere
find "$APP" \( -name '*.app' -o -name '*.xpc' \) -maxdepth 4 | while read -r b; do
  codesign -d --entitlements - --xml "$b" 2>/dev/null | grep -q get-task-allow && echo "get-task-allow: $b"
done

# Version
/usr/libexec/PlistBuddy -c 'Print CFBundleShortVersionString' -c 'Print CFBundleVersion' "$APP/Contents/Info.plist"
```

Expected results:
- every `lipo` line says `arm64`;
- both `spctl` calls say `accepted` with `source=Notarized Developer ID`;
- no `get-task-allow` line;
- the version is 1.5, and the build number matches step 0.

## 4. Smoke test

- Install `dist/GarageInstaller_arm64.pkg` by double-clicking it. There should be no Gatekeeper warning.
- Launch Garage from /Applications. The setup assistant appears; add one source; Update Everything; search finds the note.
- Garage → About shows the Developer ID build.
- `/Applications/Garage.app/Contents/MacOS/garage version` prints the version, and `garage quit` quits.

## 5. Report back (do not publish)

Put the following in `/mnt/project-files/release/1.5-alpha-build.md`:
- the commit, build number and notarization submission IDs;
- the check output;
- the SHA-256 of both files in `dist/` (`shasum -a 256 dist/*`).

Keep `dist/` on the Mac. Publishing waits for Rick's decision on how the alpha is distributed:
- a GitHub pre-release with no appcast entry (recommended), or
- the appcast.

The `v1.5` tag stays reserved for the final release. `publish_appcast` insists that the tag equals `v<CFBundleShortVersionString>`, so an alpha appcast entry would burn it.
