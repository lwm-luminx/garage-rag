# Garage 1.5 alpha 2

This is the second pre-release of Garage 1.5 for testing. It is signed and notarized for Developer ID. It isn't in the update feed, so no one is offered it as an update, and once the final 1.5 is in the feed, this build updates to it on its own. Report problems through Help → Report a Bug… (⇧⌘B) or on GitHub issues.

The App Store build is not part of this alpha.

**Garage 1.5 runs on Apple Silicon Macs only.** Everything in the [alpha 1 notes](https://github.com/rickmark/garage-rag/releases/tag/v1.5-alpha.1) still applies, including backing up `~/Library/Application Support/GarageApp` before you upgrade.

## Changes since alpha 1

- **No more "install developer tools" prompt.** On a Mac without the Command Line Tools, Garage's background services used to trigger macOS's prompt to install them. Garage now checks quietly and skips git authorship when git isn't installed.
- **The installer carries a stapled app.** The app inside the installer is now notarized and stapled before the installer is built, so Gatekeeper can check it without going online.
- **Setup assistant layout.** The data page keeps its three location columns when the scroll bar is always shown, for example with a mouse attached.
- The app now declares the encryption it uses (for TLS to an https Ollama or LM Studio server), as App Store Connect requires.
