# Garage 1.5 alpha 1

This is a pre-release of Garage 1.5 for testing. It is signed and notarized for Developer ID. It is not in the update feed, so no one is offered it as an update. Once the final 1.5 is in the feed, this build updates to it by itself. Report problems through Help → Report a Bug… (⇧⌘B) or GitHub issues.

The App Store build is not part of this alpha.

Garage 1.5 is the polished 1.0: every page has been redesigned, Garage lives in the menu bar, it reads Mail and Messages, and it keeps its own updates from now on.

**Garage 1.5 runs on Apple Silicon Macs only.**

## Before you upgrade

Your library carries over as is. Garage moves its data folder into a shared location and copies its database password into the Keychain on first launch, leaving the old copies in place. Still, it's a good idea to back up `~/Library/Application Support/GarageApp` first.

## What's new

**A redesigned app**
- **Status** shows what needs your attention first, then your library (Scan, Read, Index, Glean) and the helper services.
- **Sources** leads with what needs fixing and what's running, with one row per source. Add a source from the location cards, and Garage names it after the folder.
- **Update Everything** scans, reads, indexes and gleans facts in one run. Garage can also offer updates when it launches.
- **Models** has separate Overall, Embedding and Distillation tabs with one row per model. You can load and unload models there, and edit the prompts used to glean facts.
- **Database** and **MCP Server** pages are redesigned too, and the sidebar is grouped into Configuration, Data and Advanced.
- Garage has a **first-run setup assistant** that walks you through sources, models and connecting your AI assistants.

**The menu bar**
- Garage lives in the menu bar. Its popover has search, one "All systems go" row (or one row that sums up any problems), and Stop for everything that's running.

**More of your life, searchable**
- **Apple Mail**: `.emlx` and `.eml` messages. Mail you sent counts as yours, and mail you received as received.
- **Messages**: each conversation becomes one document.
- **HEIC/HEIF photos** are read with text recognition, like other images.
- **Facts**: Garage can glean short, sourced facts from your documents, with more than one set of prompts.

**Faster and gentler**
- The default embedding model loads when Garage starts. The facts model loads only while it's needed.
- When a document changes, only the parts that changed are indexed again.
- Garage remembers files that have no text or can't be read, and skips them until they change.
- Online-only cloud files that haven't changed aren't downloaded again.

**Privacy and security**
- Garage's local gRPC port now needs a secret that changes each launch.
- The database password and LM Studio token are kept out of the system log.
- Bug reports redact more kinds of secrets.
- The helper services run with the hardened runtime.

**Updates**
- Garage now checks for updates itself (Garage → Check for Updates…).

## Also

- `garage quit` quits every running Garage from the terminal.
- The About panel shows which build you have (Developer ID or App Store).
- Many fixes to help text, names and VoiceOver labels.
