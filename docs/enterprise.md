## What we're building toward

<div class="grid">
  <div class="card">
    <h3>Deploy to every computer</h3>
    <p>Install and configure Garage across a fleet with the device-management tools you already use, with sources, models and assistants set up before anyone opens it.</p>
  </div>

  <div class="card">
    <h3>Policy you can audit</h3>
    <p>Set which sources may be indexed, which local model servers {% include term.html term="embedding" text="embeddings" %} may use, and which destinations the {% include term.html term="egress" %} allowlist approves — centrally, and in writing.</p>
  </div>

  <div class="card">
    <h3>Your data stays in the company</h3>
    <p>Your company's data remains in the company: it is indexed on infrastructure your organization runs, never sent to a cloud provider. Agents can search only the sources you permit, and the guarantee is enforced by tests, not by promise.</p>
  </div>
